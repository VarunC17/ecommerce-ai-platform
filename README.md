# E-Commerce AI Platform

An end-to-end e-commerce analytics and artificial intelligence platform designed to analyze sales, customers, products, and business performance.

## Project Status

🚧 Currently under development.

## Planned Features

- Data cleaning and preprocessing
- Exploratory data analysis
- SQL-based business analytics
- Sales analytics
- Customer segmentation
- Customer Lifetime Value (CLV) analysis
- Sales forecasting
- Demand prediction
- Product recommendation system
- Market basket analysis
- Interactive dashboards
- Machine learning models
- Streamlit web application

## Technology Stack

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Scikit-learn
- XGBoost
- Prophet
- Matplotlib
- Plotly
- Power BI
- Streamlit
- Git and GitHub
