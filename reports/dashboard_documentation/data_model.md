# Data Model Documentation

# ECOMMERCE-AI-PLATFORM

## Overview

The Power BI data model for the **ECOMMERCE-AI-PLATFORM** project is designed using a **star-schema-inspired architecture**, where central fact tables store transactional and analytical data while dimension tables provide descriptive attributes for filtering and reporting.

The model integrates business intelligence, machine learning outputs, recommendation systems, sales forecasting, and AI-generated insights into a unified reporting layer.

---

# Data Model Design

The dashboard follows a dimensional modeling approach to improve reporting performance, simplify relationships, and support interactive filtering.

The model consists of:

- Fact Tables
- Dimension Tables
- AI Insight Tables
- KPI Tables
- Calendar Dimension
- Supporting DAX Measures

# Relationships

The dashboard uses one-to-many relationships wherever possible.

### Calendar Relationships

```
Dim Calendar
      │
      ├── Fact Sales
      ├── Fact Customer Features
      ├── Fact Sales Forecast
```

---

### Customer Relationships

```
Dim Customer
      │
      ├── Fact Sales
      ├── Fact Customer Features
      ├── Fact Customer Segmentation
      ├── Fact Customer CLV
      ├── Fact Customer Churn
      └── Fact Recommendations
```

---

### Product Relationships

```
Dim Product
      │
      ├── Fact Product Analytics
      └── Fact Recommendations
```

---

### Seller Relationships

```
Dim Seller
      │
      └── Fact Seller Analytics
```

---

# Relationship Direction

Relationship filtering follows Power BI best practices.

- One-to-Many Relationships
- Single Direction Cross Filtering
- Active Relationships whenever possible
- No unnecessary Many-to-Many relationships

---

# Measures

Business calculations are implemented using DAX measures rather than calculated columns whenever possible.

Examples include:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Average CLV
- Churn Rate
- Retention Rate
- Forecast Revenue
- Product Revenue
- Category Revenue

---

# Design Principles

The data model was designed with the following objectives:

### Performance

- Optimized relationships
- Reduced redundancy
- Efficient aggregations

### Scalability

The model can support additional datasets and future analytical models without significant redesign.

### Maintainability

Fact and dimension tables are logically separated to simplify future maintenance.

### Reporting

The structure supports interactive filtering, cross-highlighting, drill-down analysis, and reusable DAX measures.

# Summary

The ECOMMERCE-AI-PLATFORM Power BI data model integrates transactional data, engineered features, machine learning outputs, forecasting results, and AI-generated insights into a unified reporting architecture.
